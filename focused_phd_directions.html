Student intellectual-ownership gate

Do not confuse hands-on work with owning the problem. A student can run the laser, fabricate the chip, write the simulation and make every plot while somebody else still owns the reasoning trajectory.

Strong chain: own unresolved problem → form/refine hypotheses → choose probe/model/intervention → observe → interpret surprises → decide next step → accumulate understanding/capability. Weak chain: advisor defines task → student executes → plots → advisor interprets/chooses next task → repeat.

Verification: prioritize student theses/defenses and multi-year student project chains; then student/alumni descriptions and project structure. PI claims about “freedom” are weak evidence alone. Before final-shortlist promotion, verify at least one real student trajectory showing substantial and growing intellectual ownership; otherwise mark ownership unverified. Strong supervision is compatible with this—the question is whether reasoning ownership grows through the PhD.

Decision filters — what these columns mean

HPC / low-level performance: separately records demonstrated ownership of performance-critical scientific or real-time code. Unknown is not a negative score; verify project-level evidence before promotion. This bonus is excluded from the existing weighted intrinsic fit pending a calibrated scoring review.

Problem importance: if solved, does the underlying problem materially matter? Unknown / bottleneck clarity: is there a genuine unresolved physical/system mechanism or predictive/control limitation, rather than merely an unpublished niche? Why-it-matters chain: how clear is the chain “unknown → inability to predict/control/build → scientific/technological consequence”? Transferable R&D capability: whether five years builds durable modelling, inference, DSP/optimization, numerical/HPC, measurement or HW/SW co-design skill. Implementation ownership: likelihood that the student closes the loop onto a real experimental/engineered system.
Intellectual / problem ownership: separate from hands-on work. Does the student increasingly own the reasoning trajectory—hypotheses, discriminating tests/models, interpretation of surprises, and what to try next? A hands-on PhD can still fail this if the advisor defines the question and every next task. Scientific outcome potential: chance of finishing able to say “I discovered/understood X.” Engineering outcome potential: chance of finishing able to say “I built/made X work.” Industry optionality: breadth/strength of credible industrial exits. Group field impact: whether this group—not merely its topic—actually moves the field/bottleneck forward.

h-index is kept separate and never drives the qualitative impact score. It is database-dependent, career-stage-dependent and field-dependent. I only populate it where I could independently verify a current metric source; missing values are deliberately shown as “—” rather than guessed.

Scoring model — explicit weights

Weighted intrinsic fit = 100%. Technical core 40%: Physics 9%, Modelling/Simulation 8%, Inference/Estimation 7%, Algorithms 4%, Computational Optimization 5%, Systems Implementation 4%, Experiment/Measurement 3%. Problem/thesis value 40%: Problem Importance 10%, Unknown/Bottleneck Clarity 6%, Why-it-matters Chain 6%, Transferable R&D Capability 5%, Implementation Ownership 4%, Scientific Outcome 4%, Engineering Outcome 3%, Industry Optionality 2%. Time/integration/advisor 20%: Long Horizon 8%, Full-stack Fit 4%, Advisor/Learning Confidence 8%.

Why: physics + modelling + inference are the central technical identity, with computational optimization also important because you enjoy turning models/algorithms into efficient constrained solutions. Algorithms and implementation remain meaningful but are supporting capabilities rather than the research objective. Experiment/measurement is valuable mainly because it closes the model→probe→infer→debug→refine loop; the project need not be experimentally dominant.

Not double-counted: Technical Flavor Fit is a summary and therefore receives 0% separately. Group Field Impact, h-index and institution visibility are context, not personal fit. Admissions difficulty is deliberately excluded from intrinsic fit. Research-next priority is a separate diligence score: Target/Safer +0.35, Target +0.20, Reach/Target +0.08, Reach −0.05. It decides where we spend research effort; it does not pretend an easier-admission group is intrinsically better.

Evidence quality: Deeply researched = repeated group/project-level investigation and stronger primary-source grounding; Moderate = group direction is credible but important diligence remains; Preliminary = ecosystem/uncertain/long-tail row that should not yet drive a decision.

Holistic attention is now a deliberately selective research-effort tier, not a viability label. Highest = primary targets deserving immediate deep investigation; High = genuine contenders deserving full profiles; Medium = retained for coverage but not where to spend time now. It synthesizes weighted intrinsic fit, actual mission/loop, fundamental-vs-engineering character, long-horizon value, admissions practicality, evidence confidence, background bridge and industry optionality. Interconnect groups were explicitly reconsidered rather than mechanically scored.
