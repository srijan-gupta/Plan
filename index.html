Frozen search thesis

Target a PhD in service of an important problem — primarily fusion, scaling compute through photonics/physical computing, or optical communications — where research includes some combination of physical modelling, inference, algorithms, experiments and implementation on real systems. Preserve and compound serious programming / optimization / HW–SW debugging capability rather than becoming analysis-only.

Four-axis fit test

Physics — real physical mechanisms matter.   Applied maths — modelling, inference, DSP, optimization, control or numerical methods.   Engineering — implementation, hardware/software, experiments, prototypes, real systems.   Slow horizon — the underlying problem can support years to decades of cumulative work.

Ideal loop: physical problem → model → simulate/infer → devise solution → implement → experiment/test → debug → refine.

This is not a prestige ranking. Priority A/B is a fit-investigation priority: which rows deserve deeper project/thesis/advisor diligence first. The purpose of this version is to be broad enough that subsequent work should mostly remove rows, not discover whole missing directions.

Problem + research depth + implementation/system loop appear especially aligned.
B Retain for project-level screening

Implementation signal
“Strong” means the lab/ecosystem visibly supports building, control, testbeds, real-time systems, prototypes or experimental deployment. It is not yet a claim about every PhD project.
Destination roles: optical systems architecture

For coherent or IM/DD optical links, seek end-to-end impairment and link models, DSP/FEC, measured-link correlation and architecture decisions. For optical I/O, seek electrical–photonic co-design, SerDes, package and signal integrity, plus lab validation. Check the actual thesis scope with the PI.

Research-stack axes

The old broad “Applied maths” and “Engineering” columns are now decomposed so the intersection is visible: Physics → modelling → inference → algorithms → computational optimization → systems implementation → experiment/measurement → impact → long horizon.

Full-stack fit is the “BAM” signal: a derived indicator that deliberately penalizes a missing layer rather than rewarding a high average. It is preliminary and should be replaced with evidence from recent theses/projects during diligence.

Coverage-first, not prestige-first

This version expands the search using bottom-up research-activity queries (real-time implementation, FPGA/GPU, diagnostics/control, inference, HW/SW and electronic-photonic co-design), not “top university” lists. Admission band is deliberately separate from institutional visibility/prestige. Reach/Target/Safety is only a rough application-planning heuristic: PhD admission depends heavily on PI funding, openings, fit and applicant pool, so “Safety” never means guaranteed.

Advisor / learning confidence is evidence confidence, not fame: thesis coherence, technical depth, student ownership, supervision/alumni evidence. Legacy rows default to “Unknown / needs thesis review” rather than inventing confidence. Industry collaboration and named partners are separate columns.

Decision filters — what these columns mean

Problem importance: if solved, does the underlying problem materially matter? Unknown / bottleneck clarity: is there a genuine unresolved physical/system mechanism or predictive/control limitation, rather than merely an unpublished niche? Why-it-matters chain: how clear is the chain “unknown → inability to predict/control/build → scientific/technological consequence”? Transferable R&D capability: whether five years builds durable modelling, inference, DSP/optimization, numerical/HPC, measurement or HW/SW co-design skill. Implementation ownership: likelihood that the student closes the loop onto a real experimental/engineered system. Scientific outcome potential: chance of finishing able to say “I discovered/understood X.” Engineering outcome potential: chance of finishing able to say “I built/made X work.” Industry optionality: breadth/strength of credible industrial exits. Group field impact: whether this group—not merely its topic—actually moves the field/bottleneck forward.

h-index is kept separate and never drives the qualitative impact score. It is database-dependent, career-stage-dependent and field-dependent. I only populate it where I could independently verify a current metric source; missing values are deliberately shown as “—” rather than guessed.

Scoring model — explicit weights

Weighted intrinsic fit = 100%. Technical core 40%: Physics 9%, Modelling/Simulation 8%, Inference/Estimation 7%, Algorithms 4%, Computational Optimization 5%, Systems Implementation 4%, Experiment/Measurement 3%. Problem/thesis value 40%: Problem Importance 10%, Unknown/Bottleneck Clarity 6%, Why-it-matters Chain 6%, Transferable R&D Capability 5%, Implementation Ownership 4%, Scientific Outcome 4%, Engineering Outcome 3%, Industry Optionality 2%. Time/integration/advisor 20%: Long Horizon 8%, Full-stack Fit 4%, Advisor/Learning Confidence 8%.

Why: physics + modelling + inference are the central technical identity, with computational optimization also important because you enjoy turning models/algorithms into efficient constrained solutions. Algorithms and implementation remain meaningful but are supporting capabilities rather than the research objective. Experiment/measurement is valuable mainly because it closes the model→probe→infer→debug→refine loop; the project need not be experimentally dominant.

Not double-counted: Technical Flavor Fit is a summary and therefore receives 0% separately. Group Field Impact, h-index and institution visibility are context, not personal fit. Admissions difficulty is deliberately excluded from intrinsic fit. Research-next priority is a separate diligence score: Target/Safer +0.35, Target +0.20, Reach/Target +0.08, Reach −0.05. It decides where we spend research effort; it does not pretend an easier-admission group is intrinsically better.

Evidence quality: Deeply researched = repeated group/project-level investigation and stronger primary-source grounding; Moderate = group direction is credible but important diligence remains; Preliminary = ecosystem/uncertain/long-tail row that should not yet drive a decision.

Holistic attention is now a deliberately selective research-effort tier, not a viability label. Highest = primary targets deserving immediate deep investigation; High = genuine contenders deserving full profiles; Medium = retained for coverage but not where to spend time now. It synthesizes weighted intrinsic fit, actual mission/loop, fundamental-vs-engineering character, long-horizon value, admissions practicality, evidence confidence, background bridge and industry optionality. Interconnect groups were explicitly reconsidered rather than mechanically scored.
