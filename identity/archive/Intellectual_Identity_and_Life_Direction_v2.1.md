# Gospel (Constitution)

## What this document is

-   A model of my intellectual identity.
-   A model of my life-direction decision process.
-   A continuously improving theory supported by evidence.
-   A document intended to remain useful even if every current career
    conclusion changes.

## Core Principles

1.  Preserve transformations, not merely conclusions.
2.  Preserve **why**, not merely **what**.
3.  Identity is more fundamental than career.
4.  Evidence updates identity → identity updates the framework → the
    framework updates hypotheses → hypotheses guide decisions.
5.  Optimize for truth, not consistency.
6.  Every release must represent the **best complete model currently
    supported by all available evidence**.
7.  Unknowns should remain explicit rather than hidden.

# Methodology

## Two Timelines

### 1. Knowledge Acquisition (Sequential)

Each discussion has a single emphasis.

Example:

Thinking → Work Style → Wonder → Contribution → ...

This keeps discussions focused.

### 2. Knowledge Publication (Holistic)

Every release is global.

Before publishing:

Observation ↓ Identity ↓ Decision Framework ↓ Evidence Register ↓
Hypothesis Confidence ↓ Open Questions ↓ Research Agenda ↓ Release

A release is **not** a snapshot of today's discussion.

It is the best complete theory available today.

------------------------------------------------------------------------

# Cooling Principle

The document cools over time.

Architecture → Very High stability

Identity → High stability

Decision Framework → High stability

Evidence Register → Continuously expanding

Hypotheses → Expected to evolve

Concrete decisions → Most fluid

Inner layers become harder to change. Outer layers remain adaptable.
